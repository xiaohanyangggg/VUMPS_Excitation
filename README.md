# VUMPS and quasi-particle excitation for FCI edge modes

This repository contains the source code accompanying the paper:

**"Chiral edge excitations of $\nu = 1/2$ fractional Chern insulators in the bosonic Hofstadter model" (DOI: https://doi.org/10.1103/kwj1-d19d)**

## Dependencies

This project depends on the [TeNPy library](https://github.com/tenpy/tenpy) v1.0.6,
which is licensed under the Apache License, Version 2.0.

## Data available
All the data supporting the findings in the main context and the supplementary material are openly available at [zenodo](https://doi.org/10.5281/zenodo.20704429).
